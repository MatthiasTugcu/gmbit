# Sound credits

Board sounds are from the Lichess open-source `standard` sound set
(github.com/lichess-org/lila, `public/sound/standard/`):

| File        | Lichess source |
|-------------|----------------|
| move.mp3    | Move.mp3       |
| capture.mp3 | Capture.mp3    |

Lichess is free/libre software (lila is AGPL-3.0). See the lila repository for
the sound assets' licensing.

Checks and checkmates have no dedicated sound — they play the move (or capture)
wood-click like any other move, so every move sounds like wood.
